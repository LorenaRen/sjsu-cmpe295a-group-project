# LLM-Driven Ethical Conflict Resolution for Multi-Robot Coordination

SJSU CMPE 295A Master's Project

## Overview

This project extends prior single-robot work on LLM-assisted ethical decision-making to fleets of robots. We are building a shared checking layer that reviews multiple robots' proposed plans together against safety, fairness, and policy rules before they run, and sends conflicting plans back to be replanned. The system is evaluated in a multi-robot environment with wheeled autonomous mobile robots (AMRs) doing tasks like delivery and service.
